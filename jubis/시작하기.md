# 주비스 자동 실행 시작하기 (승주용)

**한 줄 요약:** PC를 켜 두면 주비스가 2시간마다 혼자 깨어나 실험하고 기록하고, 저녁에 텔레그램으로 보고한다. 실전 봇은 절대 안 건드린다.

## 주비스가 하는 것 / 안 하는 것
| 한다 | 안 한다 |
|---|---|
| 실전 봇 로그 읽고 관찰 기록 | 엔진 파일·`my_keys.py`·`run_bot.bat` 수정 |
| 새 가설을 세우고 규칙·합격 기준을 먼저 봉인 | 실제 주문, 봇 켜기/끄기 |
| 장 끝난 뒤 리플레이로 실험 | 운용자본·재투자 비율 바꾸기 |
| 일기·보고서 쓰기, 텔레그램 보고 | 결과 보고 기준 바꾸기 |
| 좋은 후보를 찾으면 **"결정해 주세요"**라고 보고 | 승주 허락 없이 실전 반영 |

> 실전 봇 파일이 조금이라도 바뀌면 자동으로 원래대로 되돌리고 주비스를 멈춘 뒤 텔레그램으로 알려준다.

## 처음 한 번만 하기 (PC에서)
1. **Claude Code 설치·로그인**: PC에 Claude Code를 설치하고, 명령 프롬프트에서 `claude`를 한 번 실행해 로그인한다.
2. **이 `jubis` 폴더를 PC로 옮기기**: `C:\Users\PC_1M\jubis` 에 둔다. (실전 봇 폴더 `C:\Users\PC_1M` 안)
3. **텔레그램 설정** (명령 프롬프트에 직접 입력. **채팅이나 파일에 쓰지 않기**):
   ```
   setx JUBIS_TG_TOKEN 봇토큰
   ```
   ```
   setx JUBIS_TG_CHAT 채팅ID
   ```
   기존 봇과 같은 텔레그램 봇을 써도 된다.
4. **(실험까지 시키려면) KRX 아이디** — 리플레이에 필요. 역시 직접 입력:
   ```
   setx KRX_ID 아이디
   ```
   ```
   setx KRX_PW 비밀번호
   ```
5. **`autopilot\install_task.bat` 더블클릭** → 끝. 이제 2시간마다 돈다.

## 평소에
- **멈추기**: `autopilot\stop.bat` 더블클릭
- **다시 켜기**: `autopilot\resume.bat`
- **완전히 없애기**: `autopilot\uninstall_task.bat`
- **지금 바로 한 번 돌려보기**: `autopilot\run_once.bat`
- 주비스가 쓴 것 보기: `reports\` (보고서), `memory\diary\` (일기), `memory\experiments\` (실험)

## PC 설정
- 윈도우 설정 → 시스템 → 전원 → **절전 모드 "안 함"** (화면 끄기는 괜찮음)
- 윈도우 업데이트 **자동 재시작 끄기** (밤사이 재부팅되면 봇·주비스 둘 다 멈춤)

## 알아둘 것
- **돈을 보장하지 않는다.** 주비스가 찾은 규칙도 새 기간에서 다시 확인해야 하고, 실전에 넣을지는 승주가 정한다.
- Claude Code 사용량을 쓴다. 2시간마다 = 하루 최대 12번. 많으면 `install_task.bat`의 `/mo 2`를 `/mo 4`(4시간마다)로 바꾸면 된다.
- 장중(평일 08:30~15:40)에는 실험을 안 하고 로그만 본다 (실전 봇과 한투 토큰이 겹치지 않게).
