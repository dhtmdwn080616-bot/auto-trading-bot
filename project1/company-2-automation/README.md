# Company 2 — 소상공인 AI 업무 자동화 외주

1차 사업체. 1번(웹)에서 들어온 고객 문의를 자동화 상품으로 연결하는 것이 1차 경로. 근거: `log/2026-10-04-research-candidates.md` 3.(1).
표기: [사실] = 리서치 파일에 출처가 있는 수치. [가정] = 근거 없는 내부 판단.

## 1. 무엇을 팔지 (상품 3개)

| 상품 | 내용 | 납기 [가정] |
|---|---|---|
| A. 카카오톡 채널 FAQ 응대 세팅 | 고객 업종의 자주 묻는 질문 20~30개 정리 → 톡채널 AI 상담/자동응답 설정 + 운영 매뉴얼. [사실] 생성형 AI 연동 심사 폐지로 즉시 연동 가능 | 3~5영업일 |
| B. 후기·문의 답글 자동 초안 키트 | 네이버 플레이스/스마트스토어 후기·문의에 대한 답글 초안을 만드는 프롬프트 세트 + 톤 가이드 + 금지 표현 목록 + 사용법 문서. 고객이 복붙으로 쓰는 "무설치" 상품 | 2~3영업일 |
| C. 반복 업무 자동화 소형 구축 | 예약 접수 정리, 견적서 자동 작성, 주간 보고 요약 등 1개 업무를 스프레드시트+스크립트 또는 노코드 도구 무료 티어로 구축 + 월 유지보수 옵션 | 7~10영업일 |

차별화 [가정, 리서치 3.(1)]: 단순 FAQ 봇은 플랫폼 기본 기능에 흡수될 가능성이 있으므로, 업종 특화 패키지(미용실·학원·병의원)와 유지보수 구독을 축으로 한다.

## 2. 타깃 고객
- 1순위: 1번 사업체 고객(이미 신뢰 형성, 사이트+자동화 묶음 제안)
- 2순위: 예약·문의가 카톡으로 몰리는 소상공인(미용실, 학원, 소형 병의원, 펜션)
- 제외: 결제·환불·의료 상담처럼 오답 책임이 큰 응대 자동화 [가정]

## 3. 가격 범위
- 시장 근거 [사실]: 크몽 패키지 예 55,000/165,000/330,000원, 5만/10만/20만원, 49만/199만/449만원. 챗봇 대행 단건 1만~15만원대, 월 유지보수 3만~10만원(2차 자료). GPT 챗봇 개발 20만원대~평균 50만원대~200만원 이상(검색 요약).
- 내부 초안 [가정, 대표 확정]:
  - A: 단건 5만~15만원대 구간(시장 챗봇 대행 단건 범위 안)
  - B: 5만원대 전후(상품 성격이 문서+프롬프트라 저가)
  - C: 20만~50만원대부터 견적, 유지보수 월 3만~10만원 [사실 범위 참조]
- 초기 2주는 상품 정의와 데모만 하고, 등록은 1번 사업체 등록 상태를 보고 결정한다.

## 4. 판매 채널
- 주: 크몽 (1번과 같은 계정, 카테고리 다름)
- 보조: 1번 고객에게 납품 후 제안(업셀). 콜드 DM·메일은 외부 발송이므로 대표 승인 전 금지.

## 5. 납품 방식
| 단계 | 에이전트 | 대표 |
|---|---|---|
| 진단 | 업무 흐름 질문지, 자동화 가능 범위 판정(p1-researcher/p1-cto) | 고객에게 전달 승인 |
| 설계 | FAQ 정리, 프롬프트·워크플로 설계, 금지 표현 목록(p1-cto, p1-marketer) | — |
| 구축 | 데모 환경에서 설정·테스트, 매뉴얼 작성(p1-cto) | 고객 톡채널/계정 권한 위임 받기, 실제 계정에서 적용 |
| 검수 | 개인정보·AI 고지·오답 책임 범위 점검(p1-qa) | 계약 조건 최종 확인 |
| 사후 | 유지보수 체크리스트, 월간 점검 보고 초안 | 고객 소통·정산 |

대표 전용: 계정 인증, 고객 계정 권한 수령, 계약·가격 승인, 과금·결제, 세금.

## 6. 법규·리스크 주의점
- 고객의 고객 개인정보 처리: 개인정보보호법상 위탁 시 계약·동의 필요. 고객 데이터를 외부 LLM에 전송하면 고지 [리서치 3.(1) 규제]
- 챗봇이 AI임을 이용자에게 알리고, 오답·오작동 책임 범위를 계약서에 명시 [리서치]
- 의료·금융·법률 상담성 응답은 자동화 범위에서 제외 [가정]
- 소상공인용 계약서·개인정보 처리 조항 템플릿을 QA가 먼저 작성·검토 [리서치 추정 항목]
- 카카오가 톡채널 AI 상담을 직접 개편(2026-09-29) [사실] → 기능 중복 여부를 상품 등록 전 재확인
