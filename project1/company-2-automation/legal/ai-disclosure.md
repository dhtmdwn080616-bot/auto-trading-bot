# AI 응대 안내 문구 및 자동화 제외 범위 (초안)

> **법률 자문이 아닌 일반 초안이며 사용 전 전문가 확인 필요.** AI 고지 의무의 구체적 범위·방식은 법령과 플랫폼 정책이 바뀔 수 있어 [확인 필요: AI 관련 법령의 이용자 고지 요건(고지 시점, 표시 방식, 대상 범위), 카카오 채널 AI 상담의 자체 고지 문구 유무]. 작성일 2026-10-04 / 작성: p1-qa / 외부 발송 금지

사용: 의뢰인 채널에 손님이 보는 문구로 쓴다. 의뢰인이 업종·말투에 맞게 고칠 수 있으나 핵심 3요소(AI 응대 사실, 틀릴 수 있음, 사람 연결 방법)는 유지한다. 카카오가 자체 AI 표시를 제공하면 중복되지 않게 조정한다.

## 1. AI 응대 안내 문구 예시

### 1-1. 채널 첫 인사/프로필 소개 (기본형)
> 안녕하세요, [상호]입니다. 이 채팅은 AI가 먼저 답변해 드립니다. AI 답변은 부정확할 수 있으니 중요한 내용은 직접 확인해 주세요. 사람과 상담하려면 "상담원 연결"이라고 입력하시거나 [전화번호]로 문의해 주세요. 운영시간: [  ]

### 1-2. 짧은 버전 (자동응답 매 답변 하단)
> ※ AI가 작성한 답변입니다. 정확한 내용은 [상호] 직접 확인이 필요합니다.

### 1-3. 개인정보 입력 주의 문구
> 이름·연락처·건강 정보·카드번호 등 개인정보는 이 채팅에 입력하지 말아 주세요. 예약은 [예약 방법]으로 해 주세요.

### 1-4. 정중한 버전 (학원·병의원 등)
> [상호] 상담 채널입니다. 일반적인 안내는 AI가 도와드리며, 상담이 필요한 내용은 담당자가 직접 답변드립니다. AI 답변은 참고용이며 최종 확인은 [상호]에 문의해 주세요.

### 1-5. 후기·문의 답글 키트(상품 B) 안내
키트로 만든 답글은 의뢰인이 확인 후 직접 게시하는 방식이다. 답글 자체에 AI 표시를 넣을지는 의뢰인이 정한다. 플랫폼(네이버 등) 정책에 AI 생성물 표시 규정이 있으면 따른다. [확인 필요: 네이버 플레이스/스마트스토어 정책]

## 2. 사람 연결 안내

### 2-1. 연결 키워드를 입력했을 때
> 담당자에게 연결해 드릴게요. 운영시간(평일 [  ]~[  ])에 확인 후 순서대로 답변드립니다. 급하신 경우 [전화번호]로 연락 주세요.

### 2-2. 운영시간 외
> 지금은 운영시간이 아니라 바로 답변이 어렵습니다. 남겨 주신 내용은 [다음 영업일 시각]에 확인하겠습니다. 급한 문의는 [전화번호].

### 2-3. AI가 답할 수 없거나 제외 범위 질문일 때
> 이 문의는 정확한 안내를 위해 담당자가 직접 확인해야 합니다. 담당자에게 전달해 드릴게요.

### 구성 원칙
- 사람 연결 방법은 키워드, 버튼, 전화 중 최소 하나 이상 항상 노출한다.
- AI가 같은 질문에 2번 이상 답하지 못하거나 손님이 불만 표현을 하면 자동으로 2-1로 넘긴다.
- 사람 연결 담당자와 응답 SLA는 의뢰인이 정하며, 수급인이 대신 약속하는 문구를 쓰지 않는다.

## 3. 자동화 제외 범위
다음은 AI가 답하지 않고 2-3 문구로 사람(사장님)에게 넘긴다. 접수 질문지 3항 답변을 합쳐 의뢰인별 목록을 확정한다.

| 영역 | 제외 내용 | 이유 |
|---|---|---|
| 의료 | 증상, 진단, 시술/약 효과·부작용, 응급 상황, 진료 가능 여부 판단 | 오답 시 건강 피해 가능. 의료 광고 관련 규제도 문제될 수 있음 [확인 필요] |
| 금융 | 대출·투자·보험 가입 권유, 수익·이자 안내, 개별 금융 판단 | 금융 규제 소지 [확인 필요] |
| 법률 | 법적 판단, 분쟁 대응 조언, 계약 해석, 소송·합의 | 변호사 업무 영역과 충돌 가능 [확인 필요] |
| 결제·환불 분쟁 | 환불 가부 판단, 결제 오류, 금액 협의, 카드 분쟁, 위약금 부과 | 금전 책임 큼. 규정 안내(문서에 있는 그대로)만 가능, 판단은 사장님 |
| 예약 확정·변경 | 예약 최종 확정, 당일 취소 예외 승인 | 의뢰인 확인 필요(질문지 3-1) |
| 개별 가격 협의 | 할인·견적 약속 | 자료 외 약속 방지 |
| 불만·클레임·위기 | 항의, 사고, 안전 문제, 언론·신고 언급 | 사람 대응 필요 |
| 개인정보 요청 | 타인 예약 조회, 개인정보 열람·삭제 요구 | 본인 확인 필요 |
| 자료에 없는 질문 | 제공 FAQ 밖 내용 | 지어낸 답 방지 |

가이드: 프롬프트/설정에 "자료에 없는 내용은 모른다고 답하고 사람 연결 안내"를 명시한다. 금지 표현("100% 보장", "최고", "완치", "무조건 환불" 등)은 접수 질문지 3-3 및 수급인 기본 목록으로 차단한다.

## 4. 납품 전 QA 점검 항목
- [ ] 첫 안내에 AI 응대 사실과 부정확 가능성 고지가 있다
- [ ] 사람 연결 방법이 모든 흐름에서 도달 가능하다
- [ ] 제외 범위 질문 테스트(의료/금융/법률/환불분쟁 각 3문항) 시 AI가 답하지 않고 넘긴다
- [ ] 자료 밖 질문 테스트에서 지어내지 않는다
- [ ] 개인정보 입력 자제 문구가 있다
- [ ] 의뢰인이 문구를 확인하고 동의했다 (질문지 6-2)
- [ ] 접수 시점에 카카오 기본 AI 상담 기능·고지 방식을 재확인했다 (README 6절)
