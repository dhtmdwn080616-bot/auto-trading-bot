# 계약 전 확인 목록

> **법률 자문이 아닌 일반 초안이며 사용 전 전문가 확인 필요.** 법 조문 번호는 확인하지 못해 적지 않았다. 작성일 2026-10-04 / 작성: p1-qa / 외부 발송 금지

## A. 대표 확인 (계약·등록 전)
계정·계약·가격·결제·세금은 대표 전용이다(README 5절).

- [ ] 사업자등록 상태와 크몽 판매자 정보(상호, 대표, 사업자번호)를 계약서 제1조에 맞게 채운다
- [ ] 크몽 약관상 외부 계약서·개인정보 조항 첨부가 허용되는지 확인한다 (크몽 약관 최신본 직접 확인)
- [ ] 크몽 연락처 교환·외부 거래 제한 정책 문구를 확인하고 제12조에 반영한다
- [ ] 크몽 환불·취소 기준과 계약서 제5조, 제11조가 충돌하지 않는지 확인한다
- [ ] 유지보수(월 구독)를 크몽에서 어떻게 판매할지(별도 상품/추가 주문)를 정한다
- [ ] 가격·수정 횟수·납기 확정 (README의 5만~15만원대, 20만~50만원대는 [가정])
- [ ] 지식재산 귀속 방식 선택: 양도 vs 이용허락 (계약서 제8조)
- [ ] 책임 한도(주문 대금 한도)와 오답 면책 범위를 수용할 수 있는지 판단한다
- [ ] 관할법원 선택
- [ ] 비밀유지 기간 확정 (기본 안 2년)
- [ ] AI 서비스(Claude) 사용 계정의 데이터 정책(학습 제외 여부, 보관 기간, 서버 위치)을 확인한다
- [ ] 포트폴리오 공개 문구, 사례 사용 정책 확정
- [ ] 의뢰인 계정 권한을 받는 방식(최소 권한, 비밀번호 요청 금지, 종료 후 회수)을 확정한다
- [ ] 접수 질문지 7항 고지(30일 보관, AI 입력)와 `privacy-clause.md` 5·8항이 같은 내용인지 확인한다
- [ ] 접수 시점에 카카오 AI 상담 기본 기능과 공식 고지 방식을 재확인한다 (2026-09-29 개편 이후)
- [ ] 의료·금융·법률 관련 업종 주문은 접수하지 않거나 제외 범위를 명시해 접수한다는 방침을 정한다
- [ ] 문서 내 [  ] 빈칸과 [확인 필요] 표시를 모두 해소한 뒤에만 의뢰인에게 전달한다
- [ ] 외부 전달은 대표 승인 후 대표가 직접(또는 승인한 채널로) 보낸다

## B. 변호사 확인 필요 항목
특정 조문은 확인하지 못했다. 아래는 확인을 요청할 질문이다.

1. 개인정보 처리위탁: 이 서비스 구조(수급인이 의뢰인 채널에 접근, AI 서비스 이용)가 위탁에 해당하는지, 위탁 문서에 필수로 들어갈 항목, 이 약식 조항으로 충분한지
2. 국외 이전: 입력 자료가 해외 AI 서버로 이전될 때 고지·동의가 필요한 경우와 그 방식
3. AI 이용자 고지: 현행 AI 관련 법령(인공지능 기본법 등 [확인 필요: 명칭·시행 시기·소상공인 적용 여부])에서 챗봇이 AI임을 알려야 하는 주체(의뢰인/수급인)와 문구 요건
4. 오답 면책·책임 제한 조항의 유효성, 약관규제 관련 법령상 불공정 조항 해당 여부 (제7조, 제10조)
5. 저작권 귀속 문구(양도/이용허락), AI 생성물의 권리 귀속·침해 책임 고지 범위 (제8조)
6. 의료·금융·법률 관련 응대 제외 범위가 충분한지, 의료 광고·금융 규제 쟁점 (`ai-disclosure.md` 3항)
7. 관할 합의, 전자적 체결·통지의 효력 (제13, 14조)
8. 크몽 약관과 외부 계약서가 충돌할 때의 우선순위 처리
9. 민감정보(병·의원 업종) 처리 시 추가 요건, 정보 유출 시 수탁자 의무
10. 의뢰인이 개인 소비자일 경우 적용될 소비자 보호 법령(전자상거래, 청약철회 등) 쟁점

## C. 세무사 확인 필요 항목
1. 크몽 정산 구조에서의 수입 인식, 부가가치세·종합소득세 처리 (개인사업자/법인 여부에 따라)
2. 세금계산서·현금영수증 발급 주체와 방식 (계약서 제5조 4항)
3. 크몽 수수료의 비용 처리, 월 유지보수 정기수입 처리
4. 해외 AI 서비스 이용료(Claude 등)의 비용 처리와 부가가치세 문제
5. 거래·계약 기록 보존 기간 (개인정보 파기 정책과 맞춰 조정)

## D. 알려진 리스크와 열린 이슈 (QA 의견)
| 우선 | 이슈 | 권고 |
|---|---|---|
| 높음 | 접수 질문지는 AI 입력 고지가 있으나 "국외 이전 가능성"은 없다 | 질문지 7항에 `privacy-clause.md` 8항 문구 반영 (대표 승인 후) |
| 높음 | 오답 면책이 과도하면 무효 소지 | 변호사 확인 전에는 "책임 전부 면제" 표현 사용 금지 |
| 높음 | 카카오 AI 상담 기능 중복 시 상품 A 가치 하락, AI 고지를 카카오가 제공하는지 불명 | 접수 시점 재확인(README 6절) |
| 중간 | 개인정보 위탁 문서가 상품별로 다를 수 있다 | 상품별 처리 여부 표 작성 후 변호사에게 질의 |
| 중간 | 크몽 약관 최신 문구를 확인하지 못했다 | 대표가 약관 최신본 확인 |
| 낮음 | 파기 시 AI 서비스 측 기록 삭제 한계 | 계약서 고지 유지 |

## E. 사용 절차 요약
1. 대표가 A항 확인 → 2. 변호사·세무사 질의(B, C) → 3. [확인 필요] 해소 → 4. 최종본을 대표가 승인 → 5. 크몽 등록/주문 시 사용. 이 전에는 의뢰인에게 보내지 않는다.
