표기: [사실] = 리서치 파일에 출처가 있는 수치. [가정] = 근거 없는 내부 판단.

| 상품 | 형식 | 내용 | 원천 |
|---|---|---|---|
| A. 외주 의뢰·납품 관리 보드 | 노션 | 의뢰 접수 → 요구사항 → 제작 → 검수 → 납품 → 후기 요청 파이프라인, 질문지 템플릿, 수정 횟수 추적 | 1번 사업체 운영 보드 |
| B. 프리랜서 매출·수수료 장부 | 엑셀/구글시트 | 플랫폼별 수수료 자동 계산(크몽 구간제 [사실] 반영), 원천징수 3.3% 계산 [사실], 월별 순수익 요약 | `finance/ledger.csv` 구조 |

## 2. 타깃 고객
- 크몽·숨고에서 외주를 시작하는 프리랜서(A·B)
- 카톡 채널로 문의를 받는 소상공인(C)
- 2번 사업체 고객(C를 납품물 일부로 제공 후 단품 판매)

## 3. 가격 범위
- 시장 근거 [사실]: 크몽 노션 템플릿 5천원~, 1만원~. 전자책 템플릿 15,000원~. 노션 전자책 14,000/35,000/200,000원.
- 수수료 [사실]: 크몽 구간제, 저가 상품이라 실효 약 21.7% 이상.
- 내부 초안 [가정, 대표 확정]: A·C 1만원 전후, B 1만~2만원 전후. 번들은 후기 확보 후.
- 저가 상품이므로 건당 순수익은 작다. 수량이 아니라 1·2번 상품의 신뢰 자산(포트폴리오)으로 본다 [가정].

## 4. 판매 채널

- 보조(2주차 이후 검토): 스마트스토어·Gumroad [사실: 채널 존재]. 자체 채널은 통신판매업 신고 면제 조건 QA 확인 후 [사실: 직전연도 거래 50회 미만 또는 간이과세자, 세부 확인 필요].
