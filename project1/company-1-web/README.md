## 2. 타깃 고객

- 제외: 쇼핑몰(결제·재고 기능), 회원제 서비스 — 납품 책임이 커서 초기에는 받지 않는다 [가정]

## 3. 가격 범위
- 시장 근거 [사실]: 크몽 랜딩페이지 평균 30만~80만원대, 최저 6만~10만원대(템플릿 수정), 프리미엄 100만원 이상. 예시 패키지 5/10/20만원, 4.9/19.9/49.9만원, 66/88/120만원. 일반 시장 50만~200만원.
- 수수료 [사실]: 크몽 70만원 이하 구간 16.4% + 결제망 3.3% + 부가세 → 10만원 건 실수령 78,330원(실효 약 21.7%).
- 내부 초안 가격 [가정, 대표가 확정]:
  - A 입문: 시장 최저가 구간(6만~10만원대)에 맞춰 첫 후기 확보용. 후기 3개 확보 후 인상.
  - B 표준: 시장 평균 하단(30만원대)부터 시작.
  - C 확장: 시장 평균 상단(80만원 전후). 초기 2주는 A·B만 공개하고 C는 문의 시 견적.
- 가격 확정은 대표 승인 사항. 위 숫자는 등록 전 영업(p1-sales)이 재검토한다.
