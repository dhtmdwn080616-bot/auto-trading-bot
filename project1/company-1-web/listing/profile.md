# 크몽 전문가 프로필 소개 문구

> 사용법: 아래 블록을 크몽 "전문가 프로필 > 소개" 칸에 붙여넣습니다. 중괄호 `{{ }}` 부분은 대표가 정해 채우세요. 이 상단 박스는 붙여넣지 않습니다.

## 대표 결정 필요 (붙여넣기 대상 아님)
- `{{닉네임}}`: 크몽 활동 이름 (ROADMAP "프로필 이름·소개·사진 결정" 항목)
- 프로필 사진: 대표 결정. 사람 사진을 쓰지 않으면 로고/일러스트도 가능합니다.
- `{{연락 가능 시간}}`: 대표가 실제로 응대 가능한 시간만 적으세요. 지키지 못할 약속은 쓰지 마세요.
- 이 문구에는 경력, 학력, 수상, 거래 건수, 후기 수를 일절 쓰지 않았습니다. 지어낸 사실이 없습니다. 대표 본인의 실제 경력을 넣으려면 대표가 직접 사실만 추가하세요.

=== 붙여넣기 시작 ===

## 한 줄 소개 (짧게 쓰는 칸용)
```
AI(Claude)를 활용해 소상공인 홈페이지를 빠르게 만들고, 운영자가 직접 검수해 드립니다.
```

## 소개 (본문)
```
안녕하세요, {{닉네임}}입니다.

저는 소상공인과 1인 사업자를 위한 홈페이지(랜딩페이지)를 제작합니다.
제작에는 AI(Claude)를 활용합니다. 기획, 문구 초안, 화면 구현을 AI로 진행하고, 운영자인 제가 결과물을 확인·검수한 뒤 납품합니다. AI를 쓰기 때문에 납기를 짧게 가져갈 수 있고, 그만큼 가격 부담을 줄이는 것이 목표입니다.

■ 이렇게 일합니다
- 가게나 사업의 실제 정보를 먼저 꼼꼼히 여쭙고, 모르는 부분은 추측하지 않고 확인을 요청드립니다.
- 사실 관계(가격, 영업시간, 주소, 자격 정보)는 의뢰인께 최종 확인을 받습니다.
- 과장 표현("최고", "1위", "100% 보장" 등)은 쓰지 않도록 권해 드립니다.
- 사용하는 이미지, 폰트, 아이콘은 무료 사용이 가능한 라이선스 자료만 쓰고 출처를 정리합니다.
- 수정 횟수, 범위, 추가 비용은 시작 전에 메시지로 분명히 말씀드립니다.

■ 지금 상황을 솔직하게 말씀드리면
- 저는 크몽에서 이제 막 활동을 시작한 신규 전문가입니다. 거래 후기가 아직 없습니다.
- 제작 샘플은 실제 업체가 아닌 가상의 업체(카페, 학원, 의원)로 만든 시연용입니다.
- 샘플은 요청하시면 링크로 보여 드립니다.

■ 제작 범위
- 원페이지 소개 홈페이지
- 학원·병의원·카페 등 업종별 랜딩페이지 (지도, 카카오톡 채널 버튼, 방문 분석 코드 삽입)
- 쇼핑몰(결제·재고), 회원제 서비스는 현재 받지 않습니다.

■ 응대 안내
- 문의는 크몽 메시지로 주세요. 응대 가능 시간: {{연락 가능 시간}}
- 주민등록번호, 계정 비밀번호 등 민감한 정보는 메시지로 보내지 마세요. 요청하지 않습니다.
```

## 프로필 하단 "AI 활용 안내" 칸 (있다면)
```
이 전문가는 AI(Claude)를 제작 도구로 활용하며, 모든 납품물은 운영자가 확인·검수 후 전달합니다.
```
