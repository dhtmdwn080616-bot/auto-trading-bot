# 문의 응대 템플릿 (웹/랜딩페이지)

> 사용법: 크몽 메시지에 복사해 `{{ }}` 를 채워 보냅니다. 고객 메시지 송신은 대표 몫입니다(에이전트는 초안만). 가격과 일정은 크몽 등록 상태와 대표가 확정한 값만 쓰세요. 고객 정보 비밀번호/주민번호는 받지 않습니다.

## 1. 첫 문의 답변

```
안녕하세요, {{고객명}}님. {{닉네임}}입니다. 문의 주셔서 감사합니다.

말씀하신 {{업종/요청 요약}} 홈페이지는 "{{상품 A 원페이지 입문 / 상품 B 업종 특화}}"로 진행 가능해 보입니다.
- 작업 기간: {{3영업일 / 5영업일}} (필요한 자료를 모두 받은 날부터 계산)
- 가격: {{크몽 서비스 가격}}원 (도메인 구입비는 별도, 의뢰인 부담이며 호스팅은 무료 서비스를 사용합니다)

정확한 안내를 위해 몇 가지만 여쭙겠습니다.
1) 업종과 상호
2) 홈페이지 목적 (문의 받기, 위치 안내, 서비스 소개 등)
3) 로고/사진 보유 여부
4) 고객 이름·연락처를 받는 문의 폼이 필요하신지

참고로 이 서비스는 AI(Claude)를 활용해 제작하고 제가 검수한 뒤 납품합니다. 아직 거래 후기가 없는 신규 서비스라서, 가상 업체 샘플을 먼저 보시도록 링크를 드릴 수 있습니다. 편하실 때 답변 주세요.
```

## 2. 견적 안내 (범위가 상품과 맞는 경우)

```
{{고객명}}님, 요청 내용을 정리해 견적을 안내드립니다.

[요청 내용]
- {{요청 사항 1}}
- {{요청 사항 2}}

[진행 상품과 금액]
- 상품: {{상품명}}
- 금액: {{금액}}원 (크몽 서비스 금액 기준)
- 작업 기간: {{N}}영업일 (자료 수령 후 기준)
- 수정 횟수: {{1회 / 2회}}

[포함되지 않는 것]
- 도메인 구입비(의뢰인 부담)
- 쇼핑몰/결제/회원 기능, 사진 촬영, 로고 제작

[범위를 넘는 요청 시]
수정 횟수를 넘거나 새 섹션·기능이 추가되면 먼저 말씀드리고 별도 협의 후 진행합니다.

진행을 원하시면 크몽에서 해당 서비스로 주문해 주세요. 주문 후 요청사항 질문지를 보내드립니다.
```

## 3. 견적 안내 (범위를 넘는 경우: 다중 페이지, 기능 추가 등)

```
{{고객명}}님, 요청하신 {{내용}}은 현재 등록된 상품 범위를 넘어서 별도 견적이 필요합니다.
정확한 견적을 위해 아래를 알려 주세요.
- 필요한 페이지 목록
- 꼭 필요한 기능
- 희망 오픈일

확인 후 금액과 일정을 안내드리겠습니다. (금액은 확정되면 안내드리며, 확정 전에는 임의로 말씀드리지 않습니다.)
다만 결제/재고가 필요한 쇼핑몰, 회원제 서비스는 현재 받고 있지 않습니다.
```

(대표 메모: 별도 견적 금액은 README 가정가(C 약 80만원 전후) 참고만 하고, 대표가 확정한 금액만 안내하세요.)

## 4. 수정 요청 응대

### 4-1. 수정 요청을 받았을 때 (범위 안)
```
{{고객명}}님, 수정 요청 감사합니다. 아래 내용으로 이해했습니다.
1) {{수정 사항 1}}
2) {{수정 사항 2}}
이 요청은 수정 {{N}}회 중 {{M}}회차로 반영하겠습니다. 예상 소요는 {{시간/영업일}}입니다.
혹시 빠진 부분이 있으면 반영 전에 알려 주세요. 수정은 모아서 말씀해 주시면 더 정확하게 반영됩니다.
```

### 4-2. 범위를 벗어난 수정 (추가 협의)
```
{{고객명}}님, 요청하신 "{{요청 내용}}"은 처음 합의한 범위(수정 {{N}}회, {{기본 구성}})를 벗어나는 변경이라 별도 협의가 필요합니다.
- 방법 1: 현재 구성은 그대로 마무리하고, 이 변경은 추가 작업으로 별도 견적을 안내드립니다.
- 방법 2: 변경 내용과 일정을 조정해 추가 작업으로 진행합니다.
금액과 기간은 확인 후 먼저 안내드리고, 동의하신 뒤에만 진행합니다.
```

### 4-3. 수정 횟수를 모두 사용했을 때
```
{{고객명}}님, 합의한 수정 {{N}}회를 모두 사용하셨습니다. 추가 수정은 별도로 협의해 드립니다. 원하시는 내용을 알려 주시면 범위를 확인해 안내드리겠습니다.
```

### 4-4. 사실 관계 확인 요청
```
{{고객명}}님, 시안에 들어간 {{가격/영업시간/주소/자격 정보}}가 실제와 맞는지 확인 부탁드립니다. 사실 관계의 최종 확인은 의뢰인께서 해 주셔야 합니다.
```

### 4-5. 과장 표현 요청 시
```
{{고객명}}님, "{{요청 표현}}" 같은 최상급/단정 표현은 표시광고법상 문제가 될 수 있어 그대로 쓰기 어렵습니다. 대신 "{{사실 기반 대안 문구}}"처럼 확인 가능한 사실로 표현하는 방법을 제안드립니다. (병·의원은 의료광고 규정상 치료 효과 단정, 환자 후기 게시 등이 제한될 수 있습니다.)
```

## 5. 시안 전달

```
{{고객명}}님, 시안이 준비되었습니다.
- 확인 링크: {{시안 링크}}
- 스마트폰과 PC에서 모두 확인해 주세요.
- 수정은 한 번에 모아서 알려 주시면 정확하게 반영됩니다. (수정 {{N}}회 포함)
- 가격, 영업시간, 주소 등 사실 정보가 맞는지 꼼꼼히 봐 주세요.
{{내용 중 확인이 필요한 부분이 있으면 여기에 적기}}
```

## 6. 납품 안내

```
{{고객명}}님, 최종본을 전달드립니다.

[전달 내용]
- 완성된 홈페이지 파일 / 공개 주소: {{링크 또는 첨부}}
- 사용 안내서 (문구 수정 방법, 이미지 교체 방법, 도메인 연결 방법)
- 사용한 이미지/폰트/아이콘 출처 목록
{{상품 B: - 분석 코드 삽입 위치와 확인 방법}}

[확인 부탁드립니다]
1) 모든 내용(가격, 영업시간, 주소, 연락처)이 실제와 일치하는지
2) 스마트폰/PC에서 정상 표시되는지
3) 문의 버튼/폼이 의도한 곳으로 연결되는지

[안내]
- 도메인 연결을 원하시면 안내서대로 진행하시거나 알려 주세요.
- 이 홈페이지는 AI(Claude)를 활용해 제작하고 운영자가 검수한 결과물입니다.
- 결과물 사용권은 구매 확정 후 의뢰인께 있습니다.
- 문제가 없으시면 크몽에서 구매 확정을 부탁드립니다. 수정이 필요하면 구매 확정 전에 말씀해 주세요.
```

## 7. 후기 요청

```
{{고객명}}님, 구매 확정해 주셔서 감사합니다.
혹시 이용해 보신 경험이 괜찮으셨다면, 크몽에 솔직한 후기를 남겨 주시면 큰 도움이 됩니다. 불편했던 점이나 아쉬운 점도 편하게 적어 주세요. 다음 작업에 반영하겠습니다.
(후기는 의뢰인께서 자유롭게 작성하시는 것이며, 특정 평점이나 내용을 부탁드리지 않습니다.)

또한 제작한 결과물을 포트폴리오로 소개해도 괜찮으실까요? (허락 / 불허) 허락하시는 경우에만 게시합니다.
```
(금지: 후기 대가로 환불·할인 제안, 평점 요청, 대리 작성. 후기 요청은 대표 승인 후 발송.)

## 8. 기타 상황별 짧은 답변

### 8-1. 가격 인하 요구
```
{{고객명}}님, 말씀 감사합니다. 금액은 현재 등록된 서비스 기준으로 안내드리고 있습니다. 범위를 줄이는 방식(예: 섹션 수 조정, 기능 제외)으로 맞출 수 있는지는 확인해 보겠습니다. 어떤 부분이 부담되시는지 알려 주시겠어요?
```
(대표 메모: 할인 금액은 대표 확정 사항. 에이전트는 숫자를 제시하지 않음.)

### 8-2. 결과 보장 요구 ("방문자/매출이 늘어나나요?")
```
{{고객명}}님, 홈페이지는 소개와 문의 경로를 만드는 도구이며, 방문자 수나 매출 증가를 약속드릴 수는 없습니다. 대신 상품 B의 분석 코드로 방문 경로를 확인하실 수 있게 구성해 드립니다.
```

### 8-3. 쇼핑몰/회원제 요청
```
{{고객명}}님, 결제·재고·회원 기능이 있는 쇼핑몰/회원제 서비스는 현재 납품 책임 범위 때문에 받지 않고 있습니다. 소개와 문의 중심의 홈페이지는 가능합니다. 이 범위로 진행해도 괜찮으실까요?
```

### 8-4. 외부 연락(카카오톡/전화) 요청
```
{{고객명}}님, 진행 내용과 합의사항은 크몽 메시지에 남기면 서로 확인하기 좋아 가급적 이곳에서 소통드리고 있습니다.
```

### 8-5. 일정 지연이 예상될 때
```
{{고객명}}님, {{사유}}로 {{항목}}이 {{N}}영업일 늦어질 수 있어 먼저 알려드립니다. 새 예상 일정은 {{날짜}}입니다. 괜찮으신지 확인 부탁드립니다.
```
