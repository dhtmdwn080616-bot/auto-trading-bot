# 유튜브 자동 업로드 설정 (대표 노트북에서 한 번만)

**주의: 이 프로그램은 제가 실제 유튜브에 대해 테스트하지 못했습니다.** 처음에는 `--dry-run`, 그다음 영상 1편(`--only 1`)으로 확인하세요. 구글 정책은 바뀔 수 있습니다.

1. 구글 클라우드 콘솔(console.cloud.google.com)에서 새 프로젝트 만들기 (대표 구글 계정)
2. "API 및 서비스" > 라이브러리 > **YouTube Data API v3** 사용 설정
3. "OAuth 동의 화면": 외부, 앱 이름 아무거나, **테스트 사용자에 본인 구글 계정 추가**
4. "사용자 인증 정보" > 만들기 > **OAuth 클라이언트 ID** > 유형 **데스크톱 앱** > JSON 다운로드 → 이 폴더에 `client_secret.json` 으로 저장
5. 설치: `pip install google-api-python-client google-auth-oauthlib`
6. 확인: `python3 upload_youtube.py --videos 영상폴더 --start 2026-10-06 --dry-run`
7. 1편 시험: `... --only 1` (처음 실행하면 브라우저가 열려 구글 승인을 받는다. 승인 후 `token.json` 생성)
8. 문제없으면 전체 실행. 하루 1편씩 21:00(KST)에 자동 공개되도록 예약된다.

## 알아둘 점 (확인 필요)
- 심사를 받지 않은(미인증) API 프로젝트로 올린 영상은 **비공개로 고정되어 공개 예약이 안 될 수 있다**고 알고 있다. 이 경우 영상은 비공개로 올라가므로 스튜디오에서 수동으로 공개/예약한다. 구글 문서에서 현재 정책 확인.
- 업로드 1건당 API 할당량을 많이 쓴다(기본 일일 한도 안에서 하루 몇 편 정도). 한도는 클라우드 콘솔에서 확인.
- `client_secret.json`, `token.json` 은 **절대 저장소나 채팅에 올리지 말 것** (.gitignore 처리됨).
