# Project1 — AI 회사

Claude의 여러 버전을 조직원으로 구성해 운영하는 AI 회사.
사람(대표)은 방향과 최종 승인만 맡고, 실행은 에이전트 팀이 한다.

## 조직도

| 역할 | 에이전트 | 모델 | 책임 |
|---|---|---|---|
| 대표 | 사람 | - | 비전, 예산, 최종 승인 |
| COO (총괄) | `p1-coo` | fable | 목표를 쪼개 팀원에게 배분, 결과 취합·보고 |
| CTO (개발) | `p1-cto` | opus | 설계, 구현, 코드 품질 |
| 리서처 | `p1-researcher` | sonnet | 시장·경쟁사·기술 조사 |
| 마케터 | `p1-marketer` | sonnet | 포지셔닝, 콘텐츠, 고객 커뮤니케이션 |
| QA/감사 | `p1-qa` | sonnet | 검증, 리스크·법규 체크 |
| 운영 보조 | `p1-ops` | haiku | 반복 작업, 정리, 요약 |
| 영업 | `p1-sales` | sonnet | 견적, 문의 응대, 상품 문구 |
| 재무 | `p1-cfo` | haiku | 장부, 수수료, 손익 |

에이전트 정의는 `.claude/agents/p1-*.md`에 있다. 조직 구조와 운영 방식은 `ORGANIZATION.md` 참고.

## 운영 원칙
1. 되돌리기 어려운 일(결제, 외부 발송, 주문, 배포)은 반드시 대표 승인 후 실행.
2. 모든 결정과 결과는 `project1/log/`에 기록.
3. 모르는 것은 추측하지 않고 리서처에게 조사시키거나 대표에게 묻는다.
4. 금융 관련 기능은 모의/읽기 전용부터 시작하고, 규제 검토(QA) 통과 후 확장.
