# 13번 사업체(소형 웹앱) 첫 제품 후보 조사 (2026-10-04, p1-researcher)

## 결론
- 1순위: **증명사진·여권사진 규격 맞추기 (브라우저 내 크롭/리사이즈/KB 압축)**
- 2순위: 견적서·거래명세서 생성기 (브라우저 인쇄/PDF)
- 주의: 검색량 수치는 이번 조사에서 확인하지 못했다(검색 도구로 네이버/구글 키워드 도구 접근 불가). 아래 "수요"는 모두 추정이며, 대표 승인 후 네이버 검색광고 키워드도구/구글 트렌드로 실측 필요.
- 확인된 사실의 근거는 웹 검색 결과 요약(2차 출처)이다. 법령·공식 규격은 1차 출처(외교부, 고용노동부, 법제처) 재확인 전에는 구현에 확정 반영하지 말 것.

- 애드센스 공식 요건: 만 18세 이상, 사이트 HTML 접근, 고품질·독창적 콘텐츠. 정보성이 부족한 얇은 페이지는 "가치가 낮은 콘텐츠"로 거절되기 쉽다는 설명이 다수(공식 https://support.google.com/adsense/answer/9724?hl=ko , 비공식 해설 https://kmong.com/article/3429--%EA%B5%AC%EA%B8%80-%EC%95%A0%EB%93%9C%EC%84%BC%EC%8A%A4-%EC%8A%B9%EC%9D%B8-%EC%A1%B0%EA%B1%B4-%EC%88%98%EC%9D%B5-%EA%B5%AC%EC%A1%B0-%EC%B4%9D%EC%A0%95%EB%A6%AC ). 소개·연락처·개인정보처리방침 페이지가 필요하다는 해설이 있음(비공식). 도구 한 페이지만으로는 승인 위험이 높다 = 추정. 설명/가이드 글을 같이 쓸 것.
- 무료 정적 호스팅은 커스텀 도메인 없이도 가능하나 애드센스는 보통 자체 도메인을 요구하는 것으로 알려져 있음(확인 필요, 도메인 비용은 "초기비용 0원"과 충돌 가능 -> 대표 결정사항).

## 후보 5개

### 1. 증명사진·여권사진 규격 맞추기 (추천)
1) 검색 의도: "증명사진 크기 조정", "여권사진 규격 맞추기", "사진 용량 줄이기 500KB", "이력서 사진 사이즈" 등 정보+즉시 해결형. 수요 규모는 추정(신청서·원서 시즌 계절성 예상, 미확인).
2) 경쟁: 존재함, 포화는 아님(추정). 확인된 사이트: 인크루트 lab(https://lab.incruit.com/editor/photo/), 잡코리아 도구(https://www.jobkorea.co.kr/service/user/tool/photo), passportphoto.kr, enhanz.io, picsize.app. 대형 취업포털이 있어 "증명사진 크기" 일반 키워드는 불리, 롱테일(용도별: 운전면허, 공무원 원서, 모바일 여권 등) 쪽이 현실적 = 추정.
3) 난이도: 낮음~중. Canvas로 크롭/리사이즈/JPEG 품질 반복 조절해 목표 KB에 맞추기. 얼굴 자동 인식은 MVP 제외(수동 가이드선).
4) 리스크: 중간. 규격이 틀리면 사용자가 접수 반려될 수 있음. 검색 결과상 모바일 여권 신청은 JPG 500KB 이하, 가로 395~431px/세로 507~550px, 일반 413x531px(3.5x4.5cm, 300dpi)로 나오나 2차 출처이므로 외교부 원문 확인 필수. "규격 보장 아님, 제출처 안내 우선" 문구 필요. 사진 업로드 없음(로컬 처리)이 오히려 신뢰 포인트.
5) 수익: 애드센스(승인 필요, 규격 가이드 글로 콘텐츠 확보 가능), 후원. 제휴: 사진관/인화 서비스는 법적 표시 문제 검토 필요. 한계: 시즌성, 무료 대형 경쟁, 광고 단가는 불명(수치 없음).

### 2. 견적서·거래명세서 생성기
1) 의도: "견적서 양식", "거래명세서 양식 엑셀", "부가세 자동계산 견적서".
2) 경쟁: 양식 다운로드 사이트 다수(oppadu.com, itool.co.kr, biznote.net, yesform.com 등 확인). 대부분 엑셀/한글 다운로드형이라 "브라우저에서 바로 입력->PDF" 형은 차별화 여지(추정). 단 양식 키워드 자체는 포화.
3) 난이도: 중. 품목 행 추가, 공급가액/부가세 10%/합계, 인쇄용 CSS로 PDF 저장.
4) 리스크: 중. 부가세 계산 오류는 금전 문서에 영향. 세금계산서 아님 문구 필수. 원 단위 반올림 규칙 고정·테스트 필요. 입력값 로컬 저장은 사업자 정보 포함 가능 -> 서버 전송 없음 명시.
5) 수익: 사업자 대상이라 광고 단가 상대적으로 나을 수 있음(추정, 근거 없음). 제휴(전자세금계산서/회계 서비스)는 가능하나 가입 링크 승인 필요. 

### 3. 학점 변환기 (4.5/4.3/4.0/100점)
1) 의도: "학점 변환기", "4.5 4.3 환산", "WES 학점".
2) 경쟁: 인크루트, 뉴스컬리, calcnara, calcbang, dacalc, uhakbrain 등 다수 확인 -> 과포화에 가까움.
3) 난이도: 매우 낮음.
4) 리스크: 낮~중. 표준 공식이 없고 비례환산은 참고용(검색 결과 설명). 제출처 환산표를 따르라는 안내 필요.
5) 수익: 트래픽 천장 낮고 계절성, 차별화 약함.

### 4. 글자수 세기 (자소서·바이트)
1) 의도: "글자수 세기", "자소서 글자수", "공백 제외".
2) 경쟁: 인크루트, modan.kr, lettercount.kr, superookie, url.kr, toolify.kr 등 9개 이상 확인 -> 과포화.
3) 난이도: 매우 낮음. 4) 리스크: 낮음(EUC-KR/UTF-8 바이트 규칙 차이만 주의). 5) 수익: 수요는 꾸준하나 상위 노출 어려움(추정).

### 5. 평 <-> ㎡ 변환기
1) 의도: "평수 계산기", "84㎡ 몇 평".
2) 경쟁: calctools, modan, jakup, k-calc, sangdammoa 등 다수 -> 과포화.
3) 난이도: 매우 낮음.
4) 리스크: 낮음(1평 = 3.3058㎡). 다만 거래·광고 문서에서 평 단위 사용 규제가 있다는 요약이 있으나(과태료 언급 포함) 근거가 2차 출처로 불명확, 법제처 확인 전엔 단정 금지. 사이트는 참고용 변환임을 명시.
5) 수익: 부동산 연계 광고 단가는 높을 수 있으나(추정) 경쟁 심함.

## 제외한 아이디어(이유)
- 주휴수당/최저임금/퇴직금 계산기: 검색 결과상 경쟁 매우 많음(2026 최저시급 10,320원 기준 도구 다수), 계산 오류가 임금 분쟁에 영향, 법률 판단으로 읽힐 위험 -> 제약 조건에 부합하지 않아 제외. 
- 만 나이 계산기: 2023-06-28 만 나이 통일법 후 수요가 있었으나 경쟁 다수, 차별화 어려움.

## 1순위 추천: 증명사진·여권사진 규격 맞추기
추천 이유: (1) 서버 없이 100% 로컬 처리 가능하고 "사진이 업로드되지 않음"이 실제 차별점. (2) 법률·의료·투자 판단 아님, 오류 시 피해가 접수 반려 정도로 제한적(단, 면책 문구 필요). (3) 용도별 롱테일 페이지(여권/면허/원서/이력서)를 정적 페이지로 늘려 콘텐츠 확보 가능 = 애드센스 승인에 유리(추정). (4) 구현 1~2일. 위험: 대형 포털과 경쟁, 시즌성, 수요 미실측.

MVP 범위 (1~2일):
1. 이미지 불러오기(드래그/선택), 모두 브라우저 내 처리.
2. 프리셋 4~5개: 여권(413x531, 500KB 이하), 일반 3x4, 이력서, 직접 입력(px, KB).
3. 비율 고정 크롭 박스(드래그/확대), 미리보기.
4. 목표 KB 이하로 JPEG 품질 자동 조절 후 다운로드, 결과 px/KB 표시.
5. 안내: 제출처 규격 우선, 외교부 규격 출처 링크, 개인정보처리방침(수집 없음), 소개/문의.
6. 가이드 글 3~4개(여권사진 규격, 용량 줄이기, 배경색 주의 등)로 콘텐츠 확보.
제외: 얼굴 인식, 배경 제거, 회원/저장, 서버 기능.

## 대표 승인/확인 필요
- 도메인 비용(0원 원칙과 충돌 가능), 애드센스 계정 신청(대표 전용), 외교부 1차 규격 재확인(QA), 키워드 실측(네이버 검색광고 도구는 계정 필요).
