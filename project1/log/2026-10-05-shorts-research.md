## 2. YouTube 파트너 프로그램(YPP) 쇼츠 수익화

(모두 2차 출처 요약. 공식 문서 직접 확인 실패.)

- 2단계 구조(검색 결과 요약): 
  - 하위 단계: 구독자 500명 + 최근 90일 공개 업로드 3개 이상 + (12개월 유효 시청 3,000시간 또는 90일 쇼츠 유효 조회 300만 회). 팬 펀딩 등 일부 기능. 출처: https://www.tella.com/blog/how-to-join-youtube-partner-program , https://vidiq.com/blog/post/youtube-partner-program-guide/
  - 전체 단계(광고 수익 배분): 구독자 1,000명 + (12개월 시청 4,000시간 또는 90일 쇼츠 유효 조회 1,000만 회). 같은 출처.
  - 공통: 활성 커뮤니티 가이드 경고 없음, 2단계 인증, AdSense 연결.
- 하위 단계가 한국에서 적용되는지는 미확인. 한국어 출처(https://carat.im/blog/youtube-shorts-revenue-conditions-methods )가 같은 수치를 전하지만 이것도 2차 자료. 스튜디오에서 대표가 확인.
- 최근 변경 후보(미검증): 한 검색 결과 요약에 "2027-02-01부터 신규 신청자는 시청 8,000시간 또는 쇼츠 2,000만 회 필요"라는 문장이 있었으나 단일 2차 출처이고 공식 확인 못함. **사실로 취급하지 말 것.**
- 쇼츠 수익 구조: 쇼츠 피드 광고 수익을 월별로 모아 크리에이터 풀에 배분, 크리에이터는 배분액의 45%를 받음. 음악 사용 시 풀로 가는 비율이 줄어듦(음악 1곡 사용 시 50%, 2곡 33%, 음악 없으면 100%). 공식 페이지 URL(접근 차단): https://support.google.com/youtube/answer/12504220 , 내용은 검색 요약 기준. 시사점: **음악 없는 영상이 유리하며 우리 제작 방식과 맞음.**
- 쇼츠 RPM: 한국어 2차 블로그가 약 0.04~0.07달러라 하나 출처 신뢰도 낮아 인용만 하고 사용하지 않음. 수익 전망 수치는 만들지 않음.

## 3. 재사용·대량생산 콘텐츠 정책, AI 표시

- 2025-07-15부터 "repetitious content" 정책이 "inauthentic content(진정성 없는 콘텐츠)"로 이름·설명이 바뀜. 대량생산·반복 콘텐츠는 **게시 금지가 아니라 수익화 불가**. 예시: 표면적 차이만 있는 서사 영상 채널, 같은 나레이션의 슬라이드쇼 채널. 타 소스를 음악 추가·배속·자르기 정도로만 바꾼 것은 불충분. 출처: https://www.contentgrip.com/youtube-tightens-monetisation/ , https://www.plagiarismtoday.com/2025/07/08/youtube-targets-inauthentic-content/ , https://www.socialmediatoday.com/news/youtube-clarifies-monetization-update-inauthentic-repeated-content/752892/ (후자는 열람 차단, 검색 요약만).
- 시사점: 같은 템플릿에 문구만 바꾼 영상 대량생산은 이 정책의 핵심 표적. 완화책(추정): 영상마다 고유한 해설·구성, 레이아웃 3~4종 순환, 사람이 검수·편집, 수익화 신청 전 영상 수 과다 방지.
- AI 사용 표시: YouTube는 현실적으로 보이는 변형·합성 콘텐츠(실존 인물이 하지 않은 말·행동, 실제 사건·장소 변조, 사실처럼 보이는 가상 장면)에 업로드 시 "변경·합성 콘텐츠" 표시를 요구. 비현실적 애니메이션, 미용 필터·색보정, 대본·아이디어·썸네일 제작 보조는 표시 불필요. 출처: https://support.google.com/youtube/answer/14328491 (접근 차단, 검색 요약), https://blog.youtube/inside-youtube/our-approach-to-responsible-ai-innovation/
- 시사점: 텍스트·그래픽 영상에 실사풍 AI 이미지를 쓰지 않으면 표시 부담이 작음. 쓰면 정책에 맞춰 표시.

## 4. 다채널 운영 시 주의

- 한 구글 계정에서 여러 채널 운영은 가능(검색 요약, 최대 100개 언급). 각 채널이 개별로 수익화 요건·정책을 충족해야 하며 동일 영상·실질적 동일 렌더를 여러 채널에 올리면 수익화 불가 및 경고 위험. 출처: https://morningscore.io/youtube-duplicate-content/ , https://vidiq.com/blog/post/types-youtube-channels-dont-get-monetized/ (모두 2차).
- 반복 위반이 많으면 채널 전체 수익화가 제거될 수 있음.
- 계정 자동 생성은 약관 위반(기존 README 기재). 채널 분리는 대표 본인 계정의 브랜드 계정으로 대표가 직접.
- 권고: 채널 1개로 10개 영상 검증 후 확장, 확장 시 채널별 주제·형식을 실질적으로 다르게.
- 업로드 자동화: API 업로드가 비공개로 제한될 수 있다는 점은 여전히 미확인. 공식 문서 열람이 막혀 있어 대표 노트북에서 확인 또는 수동 예약 업로드.

## 5. 1순위 제안

주제: 헷갈리는 한국어 표현 퀴즈 + "사장님 간판·메뉴판·안내문 맞춤법" 시리즈.
이유: 위험 최저, 소재가 넓어 고갈 완화, 음악 불필요, 소상공인 연결(간판·메뉴판 교정 소재 → 프로젝트원스튜디오 웹·견적서 서비스 안내를 프로필 링크로, 영상 본문 광고 금지). 약점: 맞춤법 채널 경쟁(추정), 반복 템플릿 위험 → 퀴즈형/비교형/실제 사례(직접 만든 가상 간판 이미지, 실존 가게 사진 금지)/한 줄 팁 4형식 순환.

콘셉트:
- 이름 후보: (1) 맞춤법 한입 (2) 사장님 맞춤법 (3) 헷갈림 해결소
  (상표·기존 채널명 중복은 대표가 YouTube 검색으로 확인)
- 형식: 9:16, 문제 제시(자막) → 3초 고민 → 정답·이유 → 한 줄 요약. 자막+그래픽, 음악 없음 또는 무음(음악은 수익 풀 감소).
- 길이: 20~35초
- 주 업로드: 초기 10개는 주 4~5회로 2~3주(대표 예약 게시). 이후 반응 보고 조정.
- 근거 표기: 모든 정답은 국립국어원 표준국어대사전·어문 규범 확인 후 출처 문구를 자막 하단에 짧게 기재. 사전에 없거나 논란 표현은 제외.
